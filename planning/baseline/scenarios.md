# Baseline scenarios

Paste scenario names in under the right category — one per line. The name must
match the KovaaK's scenario name exactly (the app tells you if it can't find any
runs, so a typo shows up immediately rather than silently doing nothing).

Baseline sensitivity for now: **45–50cm**.

Format:

```
- <Exact Scenario Name> | <optional short note shown next to it>
```

---

## Run requirements

**Tier 1 — quick check.** Rough, but enough to spot obvious problems.
Spread across 20cm / 50cm / 80cm:
- minimum: 10–15 runs
- recommended: 20–40 runs
- highest accuracy: 40–60 runs

**Tier 2 — full skill map.** Spread across 20 / 30 / 40 / 50 / 60 / 70 / 80cm:
- minimum: 10–15 runs
- recommended: 20–40 runs
- highest accuracy: 40–60 runs

Not every scenario needs Tier 2 — most target one specific weakness, so Tier 1
plus the right scenario often answers the question faster.
